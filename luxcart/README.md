# LuxCart - E-Commerce Mobile App

LuxCart is a cross-platform e-commerce application developed using Flutter and Provider state management. It provides a clean, responsive shopping interface for mobile users.

## Key Features

- **Interactive Home Screen**: Featured banners, product categories, and search capabilities.
- **Product Detail Screens**: View detailed specifications, product variants, ratings, and gallery images.
- **Cart Management**: Dynamic quantity adjustments, total calculations, and item management.
- **Favorites and Wishlist**: Dynamic favorite tracking powered by Provider state management.
- **Checkout Flow**: Direct purchase capability with order summary and shipping details.
- **User Profile and Notifications**: Profile management and in-app notifications screen.

## Tech Stack

- **Framework**: Flutter (Dart)
- **State Management**: Provider
- **Design**: Material Design, Cupertino Icons

## Getting Started

### Prerequisites

Ensure you have Flutter SDK installed on your system.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/abinjoyal/LuxCart_E-commerce_app.git
   ```

2. Navigate to the project directory:
   ```bash
   cd luxcart
   ```

3. Install dependencies:
   ```bash
   flutter pub get
   ```

4. Run the application:
   ```bash
   flutter run
   ```
